Grain// Pro - Manuale

Simulazione fisica della pellicola, eseguita 100% in locale.

  • Intensity: Quantità totale di grana. Modificando solo questo, il rendering è istantaneo (Cache attiva).
  • Size (ISO Proxy): Dimensione spaziale. Più alto = pellicola più sensibile. Ricalcola il blur.
  • Clumping: Aggregazione. Basso = rumore digitale. Alto = grumi chimici realistici. Ricalcola il blur.
  • Shadow Bias: Valori bassi concentrano la grana nelle ombre. Valori alti la rendono uniforme. (Cache attiva).
  • Color Indep.: 0 = grana B/N. 100 = 3 strati RGB indipendenti.

Novità Pro: Usa il tasto ◐ per lo split screen Before/After. Le prestazioni sono state ottimizzate calcolando il box blur solo quando strettamente necessario, sfruttando la memoria per le variazioni di intensità.
